## 📝 Descripción del Proyecto

Este proyecto consiste en el desarrollo de la página web oficial para el **Rotary Club de La Falda**.

El propósito principal del sitio es:

* **Promocionar** las actividades, proyectos sociales y eventos del club.
* **Informar** a la comunidad sobre la misión de Rotary y cómo participar.
* Proporcionar **contacto** directo con los miembros de la organización.

---

## 💻 Tecnologías Utilizadas

Este sitio web está construido utilizando tecnologías estándar de desarrollo web para asegurar accesibilidad y facilidad de mantenimiento:

* **HTML5:** Estructura fundamental y contenido del sitio.
* **CSS3:** Estilos visuales y diseño responsivo para una experiencia óptima en cualquier dispositivo.
* **JavaScript:** Scripts para manejar la interactividad del usuario (navegación, formularios, etc.).
